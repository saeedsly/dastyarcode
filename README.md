# 🤖 دستیار — Dastyar

**دستیار همه‌کاره‌ی هوشمند روی کامپیوتر خودت**

یک عامل هوش مصنوعی واقعی که فایل‌ها را مدیریت می‌کند، برنامه باز می‌کند، در اینترنت
جست‌وجو می‌کند، ورد/اکسل/پاورپوینت/PDF می‌سازد، از صفحه عکس می‌گیرد و می‌بیند،
تایپ و کلیک می‌کند، با صدای فارسی حرف می‌زند و هر کار دیگری که بخواهی.

`ویندوز ۷ SP1 / ۸ / ۸.۱ / ۱۰ / ۱۱` · `بدون نیاز به دسترسی مدیر` · `۱۲۰+ ابزار واقعی` · `فارسی و آفلاین‌پذیر`

## 🚀 نصب (۲ دقیقه)

### راه اول — نصب خودکار (پیشنهادی)

1. این مخزن را دانلود کن (Code → Download ZIP) و از حالت فشرده خارج کن.
2. روی فایل **`installer\install.cmd`** دوبار کلیک کن.
3. تمام. میان‌بر **«دستیار»** روی دسکتاپ ساخته می‌شود و برنامه باز می‌شود.

نصب‌کننده:
* اگر پایتون نداشته باشی، یک **پایتون اختصاصی** (بدون نیاز به دسترسی مدیر) داخل پوشه‌ی برنامه می‌سازد؛
* بسته‌های اختیاری صدا و پنجره (`edge-tts`, `pywebview`) را نصب می‌کند؛
* میان‌بر دسکتاپ و منوی Start می‌سازد.

### راه دوم — اگر پایتون داری

```bat
git clone https://github.com/saeedsly/dastyarcode.git
cd dastyarcode
python -m dastyar run
```

### راه سوم — بسته‌ی exe (برای هدیه دادن به دوستان)

```bat
cd installer
build_exe.cmd
```
خروجی: `dist\Dastyar\Dastyar.exe` و فایل zip آماده‌ی انتقال. → [راهنما](installer/BUILD_EXE.md)

## 🔑 اتصال به هوش مصنوعی

بار اول که باز کنی، صفحه‌ی **تنظیمات** می‌گوید چه کار کنی. چند گزینه‌ی رایگان:

| ارائه‌دهنده | هزینه | چرا خوب است |
|---|---|---|
| **OpenRouter** | رایگان شروع می‌شود | یک کلید، صدها مدل (Claude، GPT، Gemini، Qwen، DeepSeek...) |
| **Google Gemini** | رایگان | سخاوتمند، فارسی خوب، بینایی قوی |
| **Groq** | رایگان | فوق‌العاده سریع (Llama 3.3 70B) |
| **DeepSeek** | ارزان | استدلال قوی |
| **Ollama** | صفر | کاملاً آفلاین روی سیستم خودت (`ollama run qwen3:8b`) |
| **حالت نمایشی** | صفر | بدون کلید و بدون اینترنت — فقط برای دیدن برنامه |

مسیر سریع با ترمینال:

```bat
dastyar key openrouter
dastyar bench          :: تست اتصال
dastyar doctor         :: بررسی کامل سیستم
```

## 🛡️ امنیت

* **سیاست ابزارها**: `بپرس` (پیش‌فرض) / `خودکار` / `فقط خواندنی` — از تنظیمات.
* **تأیید انسانی** برای ابزارهای خطرناک: حذف، خاموشی، رجیستری، اجرای کد، دانلود، تایپ در پنجره.
* **سندباکس مسیرها**: به‌صورت پیش‌فرض فقط Desktop/Documents/Downloads/Pictures؛
  دسترسی کامل فقط با تیک صریح خودت.
* **کلید API** با DPAPI ویندوز رمز می‌شود (فقط همان کاربر همان سیستم می‌تواند بخواند).
* **هیچ سروری از ما در میان نیست** — کلید مستقیم به ارائه‌دهنده می‌رود؛ همه‌چیز لوکال است.
* سرور وب پیش‌فرض فقط روی `127.0.0.1` گوش می‌دهد — نه فایروال ویندوز/مک می‌پرسد،
  نه کسی در همان وای‌فای می‌تواند کامپیوترت را کنترل کند.
  برای استفاده از موبایل: `dastyar serve --host 0.0.0.0` → یک **کد دسترسی** چاپ
  می‌شود و آدرس با `?token=...` باز می‌شود.

> ⚠️ این ابزار دسترسی واقعی به کامپیوتر می‌دهد. برای کارهای حساس `بپرس` را روشن نگه دار.

## ⌨️ دستورهای خط فرمان

```bat
dastyar run                :: اجرای کامل (پنجره + سینی سیستم + میان‌بر سراسری)
dastyar serve --no-browser :: فقط سرور وب (فقط همین کامپیوتر)
dastyar serve --host 0.0.0.0 :: در دسترس موبایل؛ کد دسترسی چاپ می‌شود
dastyar chat               :: گفت‌وگو در ترمینال
dastyar ask "هوا چطوره؟"    :: یک سؤال، بدون گفت‌وگو
dastyar doctor             :: بررسی سیستم و رفع مشکل
dastyar key openrouter     :: تنظیم کلید (مخفی تایپ می‌شود)
dastyar config policy auto :: تغییر سیاست
dastyar tools              :: فهرست ۱۲۰ ابزار
dastyar bench              :: تست اتصال مدل
dastyar update-check       :: نسخه‌ی جدید؟
dastyar reset              :: پاک کردن تنظیمات
```

## 🔧 سفارشی‌سازی

**شخصیت دستیار** — تنظیمات → «شخصیت و دستور سیستمی»
```
تو دستیار من هستی. خودمانی و کوتاه حرف بزن، شوخی کن،
ولی هیچ‌وقت بدون اجازه فایلی را پاک نکن.
```

**مهارت جدید** — یک فایل `.md` در `%APPDATA%\Dastyar\skills\` بساز:
```markdown
---
name: ترجمه
triggers: ترجمه, translate, برگردان
---
برای ترجمه: اول زبان مبدأ و مقصد را تشخیص بده، اصطلاح‌ها را
به فارسی طبیعی برگردان (نه ترجمه‌ی تحت‌اللفظی)، در پایان یک
جدول از جمله‌های کلیدی بده.
```

**میان‌بر سراسری** — پیش‌فرض `Ctrl+Alt+Space`؛ در تنظیمات `hotkey` را عوض کن.

## 🧪 تست و توسعه

```bash
python3 -m unittest discover -s tests -v   # ۴۱ تست (شامل یک سرور LLM تقلبی)
```

ساختار پروژه:

```
dastyar/
  agent.py      حلقه‌ی عامل (فکر → ابزار → مشاهده → جواب) با استریم
  llm.py        کلاینت OpenAI-compatible (بدون requests) + tool calling + retry
  server.py     سرور HTTP + SSE (stdlib) + API
  desktop.py    لانچر پنجره/سینی/میان‌بر سراسری
  winhelp.py    سینی سیستم و hotkey با ctypes (بدون pystray)
  voice.py      TTS/STT چندموتوره
  skills.py     مهارت‌های خودکار
  secret.py     رمزنگاری کلید با DPAPI
  tools/        ۱۲۰ ابزار در ۲۰ ماژول
  web/          رابط تک‌صفحه‌ای (HTML/CSS/JS بدون build) + فونت وزیرمتن
  assets/       آیکن و فونت برای PDF
installer/      install.cmd / build_exe.cmd / uninstall.cmd
tests/          تست‌های بدون وابستگی
```
