# Vazirmatn font

Persian UI font bundled with Dastyar so the app looks right **offline**
(no CDN, no Google Fonts — important behind filters).

* Source: <https://github.com/rastikerdar/vazirmatn> (v33.0.3, npm package `vazirmatn`)
* License: SIL Open Font License 1.1 — see `OFL.txt`
* Files: `vazirmatn-{regular,medium,bold}.woff2` (UI) and
  `../../assets/Vazirmatn-{Regular,Bold}.ttf` (embedded into generated PDFs)
