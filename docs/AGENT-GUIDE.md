# راهنمای انتخاب ایجنت — «کدام ایجنت خفن است و برای من مناسب است؟»

> این فایل نتیجه‌ی بررسی مخزن‌های گیت‌هاب (نوامبر ۲۰۲۶) است تا بدانی **دستیار (Dastyar)**
> در چه جایگاهی نشسته و اگر خواستی حرفه‌ای‌تر بروی، سراغ چه پروژه‌هایی بروی.
> تو این پروژه را داری چون: **همه‌ی ویندوزها (حتی ۷) + فارسی واقعی + صفر وابستگی + دسترسی کامل به سیستم**.

---

## ۲) چطور انتخاب کنم؟

* **فقط می‌خواهی روی همین ویندوز همه‌کاره باشد؟** → همین پروژه. نه Docker، نه نصب سنگین، فارسی.
* **سیستم قوی و برنامه‌نویسی مهم است؟** → `goose` (رسمی، آپاچی ۲) یا `opencode`.
* **می‌خواهی عامل با چشم ببیند و کلیک کند؟** → کنار دستیار، `UI-TARS-desktop` را هم نصب کن.
* **می‌خواهی از تلگرام دستور بدهی؟** → `openclaw`.
* **کاملاً آفلاین و بدون کلید؟** → این پروژه + [Ollama](https://ollama.com) (`ollama run qwen3:8b`).

## ۳) مدل خوب برای فارسی (تجربه‌ی عملی)

| مدل | از کجا | یادداشت |
|---|---|---|
| `google/gemini-2.5-flash` | OpenRouter / Google AI Studio | بهترین تعادل کیفیت/قیمت/سرعت برای فارسی |
| `anthropic/claude-sonnet-4.5` | OpenRouter | بهترین برای کارهای چندمرحله‌ای و نوشتن |
| `openai/gpt-4o-mini` | OpenAI | ارزان و مطمئن، بینایی خوب |
| `deepseek/deepseek-chat-v3` | OpenRouter / DeepSeek | ارزان، استدلال خوب |
| `qwen/qwen3-32b` | Groq (رایگان) | سریع‌ترین گزینه‌ی رایگان |
| `qwen3:8b` (محلی) | Ollama | آفلاین، روی ۸ گیگ رم خوب کار می‌کند |

> **نکته:** برای کار با ابزارها (tool calling) مدل‌های Gemini 2.5، Claude 4.5، GPT-4.1/4o
> و Qwen3 بهترین نتیجه را می‌دهند. مدل‌های خیلی کوچک ابزار را درست صدا نمی‌زنند.

## ۴) آیا این پروژه امن است؟

* کد کوچک و خواناست (بدون وابستگی ثالث)، همه‌چیز لوکال روی سیستم خودت.
* سیاست «بپرس» پیش‌فرض است: هر کار خطرناک باید تأیید شود.
* کلید API با DPAPI ویندوز رمز می‌شود و هیچ‌وقت به سرور واسط نمی‌رود.

برای کارهای حساس `policy` را روی `ask` نگه دار و `allow_all_paths` را روشن نکن.
