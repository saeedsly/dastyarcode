# شروع سریع در ۵ دقیقه

## ۱. نصب

روی `installer\install.cmd` دوبار کلیک کن و صبر کن تا میان‌بر «دستیار» روی
دسکتاپ ساخته شود. (بدون دسترسی مدیر، ویندوز ۷ تا ۱۱)

## ۲. کلید هوش مصنوعی (رایگان)

روزی که اولین بار باز می‌شود، بالای صفحه‌ی **تنظیمات** یک نوار آبی می‌بینی:

1. یکی از دکمه‌ها را بزن:
   * **OpenRouter** → [openrouter.ai/keys](https://openrouter.ai/keys) → کلید `sk-or-...`
   * **Gemini** → [aistudio.google.com/apikey](https://aistudio.google.com/apikey)
   * **Groq** → [console.groq.com/keys](https://console.groq.com/keys)
2. کلید را در فیلد «کلید API» بچسبان.
3. **ذخیره** → بعد **تست اتصال**.
4. اگر سبز شد ✅ تمام است؛ برگرد به «گفت‌وگو».

> می‌خواهی کاملاً آفلاین باشد؟ [Ollama](https://ollama.com) را نصب کن،
> `ollama run qwen3:8b` را بزن و در تنظیمات **Ollama** را انتخاب کن.

## ۳. اولین دستورها

| بگو | چه می‌شود |
|---|---|
| «تو دسکتاپ چی هست؟» | فایل‌ها را می‌خواند |
| «یک اکسل از هزینه‌های ماه بساز» | فایل `.xlsx` واقعی با فرمول |
| «یک پاورپوینت ۷ اسلایدی درباره X» | فایل `.pptx` واقعی |
| «اسکرین‌شات بگیر، این خطا چیه؟» | عکس + تحلیل بینایی |
| «فلان فایل PDF رو خلاصه کن» | متن را می‌خواند |
| «هر روز ۹ صبح یادم بنداز» | اعلان ویندوز |
| «یادت باشه اسم من سعیده» | در حافظه ذخیره می‌شود |

## ۴. امنیت

* پیش‌فرض سیاست **«بپرس»** است: برای حذف/خاموشی/رجیستری/اجرای کد تأیید می‌گیرد.
* دسترسی فایل‌ها فقط به Desktop/Documents/Downloads/Pictures محدود است
  تا خودت تیک «دسترسی آزاد» را نزنی.
* کلید API با DPAPI ویندوز رمز می‌شود.
* سرور فقط روی `127.0.0.1` باز می‌شود؛ برای موبایل `dastyar serve --host 0.0.0.0`
  و بعد آدرس چاپ‌شده را با کد دسترسی باز کن.

## ۵. اگر مشکلی بود

```bat
dastyar doctor
```
همه‌چیز را بررسی می‌کند و راه‌حل می‌دهد. → [راهنمای کامل](../README.md#-مشکلات-رایج)
